# Sri Aswartha Narayana Swamy Traders

This is a Vite + React agricultural shop website.

## Project Structure

- `index.html`
- `package.json`
- `vite.config.js`
- `README.md`
- `public/`
- `src/`
  - `main.js`
  - `App.jsx`
  - `App.css`
  - `components/`

## Run locally

```bash
npm install
npm run dev
```
